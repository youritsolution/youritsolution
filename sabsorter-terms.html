3. Description

SABSorter helps place a shared iPad into the correct location in Jamf School. In its default QR mode it displays the device serial number as a QR code for an administrator to scan. When your organisation provides API connection details through Managed App Configuration, a self-service mode lets a staff member move the device to a chosen location directly from the app.
