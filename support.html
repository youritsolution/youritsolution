VirtualMac Studio

Support

VirtualMac Studio is a native macOS app for creating and managing virtual macOS machines on Apple silicon Macs.

Contact

Support email: support@youritsolution.dk

Website: https://youritsolution.dk

Company: Your IT Solution

What We Can Help With

  • Creating a VM and installing macOS
  • Restore image download or validation issues
  • Shared folders and custom storage locations
  • Performance tuning, CPU and RAM configuration
  • Save state, clone, and disk expansion workflows
  • App Store build and sandbox behavior questions

Before Contacting Support

Please include:

  • Your Mac model and host macOS version
  • The VirtualMac Studio version
  • A short description of the issue
  • Whether the issue happens during install, startup, or while the VM is running
  • Any error message shown in the app

Privacy Reminder

If you choose to send logs or screenshots, please review them first for local file paths, machine names, or other details you do not want to share.
