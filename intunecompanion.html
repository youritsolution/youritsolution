Intune Companion

A Mac-native workbench for Microsoft Intune and Entra administration.

Intune Companion helps administrators export tenant configuration into reusable packages, compare packages or live tenants, dry-run imports before making changes, copy supported workloads between tenants, transform packages before reuse, and generate reports, architecture summaries, and diagnostics from one focused desktop workflow.

Highlights

Built for serious admin work without forcing everything through the browser.

Export and document

Export supported Intune and Entra configuration into structured packages and generate reports, executive summaries, and diagnostics that are easy to keep or hand over.

Compare and review

Compare one package with another or compare a package against a live tenant to review drift, missing objects, matching objects, and unsupported areas before you change anything.

Import with validation

Dry-run import plans before making real changes, map dependencies, and keep the workflow focused on safe review instead of trial-and-error in the portal.

Specialist tools included

Intune Companion also includes targeted admin workflows for Administrative Templates, Registry Values, package transformation, tenant copy, and diagnostics collection.

Workflow

One desktop tool for the main lifecycle of tenant configuration work.

Intune Companion is designed around the real sequence of work administrators follow when they need to understand, migrate, or reuse configuration:

  • Connect to a tenant
  • Export supported objects into a reusable package
  • Compare packages or compare a package against a live tenant
  • Transform names or values before reuse when needed
  • Dry-run imports and validate mappings
  • Run real import or tenant copy workflows when the plan is safe
