SAB Roster Flow

Support

Contact information, requirements, and troubleshooting for SAB Roster Flow.

Contact

  • Email: support@youritsolution.dk
  • Website: youritsolution.dk
  • GitHub Discussions: Community

System Requirements

  • macOS 14.6 (Sonoma) or later
  • Intel or Apple Silicon Mac
  • Internet access to Microsoft Graph and ASM SFTP endpoint
  • Entra ID privileges for app registration (Global Admin recommended for Magic Setup)
  • Apple School Manager SFTP credentials

What This App Does

  • Discovers Microsoft Entra ID groups and classifies members as teachers or students
  • Generates Apple School Manager compatible CSV files (students, staff, classes, courses, locations, rosters)
  • Uploads the required six-file package to ASM via SFTP
  • Supports rule-based role assignment and smart location mapping
  • Provides headless automation via URL scheme for scheduled sync

Troubleshooting

  • Client Secret missing: Re-enter in Connect and click Save Secret to Keychain
  • SFTP password missing: Re-enter password and click Save Password to Keychain
  • No students warning: Review selected group membership and role rules in People Map
  • Hidden membership group returns 0 members: Verify Member.Read.Hidden permission is granted
  • Upload succeeds but ASM not updated: Validate package structure and check ASM processing status

Before Contacting Support

  • Check the Activity Log (toolbar) for error messages and warnings
  • Run connection tests for both Microsoft and SFTP in the Connect tab
  • Try a local CSV export first (Generate and Save CSVs) and review the files before uploading
  • Note which step in the wizard the issue occurs at

Privacy

SAB Roster Flow processes school roster data locally and uploads only the required CSV package to ASM. See the privacy page for full details on data handling.
