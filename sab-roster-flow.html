SAB Roster Flow

Keep Apple School Manager class rosters current using your Microsoft Entra ID tenant data.

SAB Roster Flow is a native macOS utility for school IT teams who need to sync class rosters from Microsoft Entra ID into Apple School Manager without manual CSV editing every time classes change. It discovers groups, classifies users as teachers or students with configurable rules, generates ASM-compatible CSV files, and uploads them via SFTP.

What It Does

A five-step wizard that turns roster sync into a repeatable workflow.

Connect

Enter Microsoft Entra and ASM SFTP connection details. Magic Setup can create the required app registration and permissions automatically using device-code authentication.

Discover

Scan your tenant for Microsoft 365 groups, security groups, or Teams. Select only the groups that should become classes in Apple School Manager.

Map People

Map Entra user attributes to ASM person fields. Choose simple owner-based role assignment or advanced rules that match on job title, department, or any extension attribute.

Map Classes

Configure class and course field mappings. Set a fixed location or use smart location mapping that derives each class location from its instructors.

Export and Sync

Generate ASM-compatible CSV files for local review, or upload the required six-file package directly to Apple School Manager via SFTP. Includes audit logs and run reports.

Headless Automation

Trigger unattended sync via URL scheme (sabflow://sync). Schedule with macOS Shortcuts or launchd for daily automated roster updates without opening the app.

Download

Signed and notarized installer for macOS.

SAB Roster Flow is distributed as a signed and notarized macOS installer package (.pkg). Download, install, and run through the five-step wizard to connect your Microsoft tenant to Apple School Manager.

  • Signed with Developer ID for Gatekeeper compatibility
  • Notarized by Apple for safe distribution outside the App Store
  • Requires macOS 14.6 (Sonoma) or later
  • Runs on both Intel and Apple Silicon Macs

Highlights

Built for school admins who need reliable roster sync, not more spreadsheet work.

Rule-based role assignment

Go beyond simple group ownership. Define rules that match on job title, department, extension attributes, or any Entra user property to classify staff and students accurately.

Smart location mapping

Derive class locations automatically from instructor attributes, or set a fixed location for all classes. The location scan discovers unique values across your tenant.

Audit and diagnostics

Every sync produces membership audit CSVs, role conflict reports, and run reports with row counts, warnings, and skip summaries. Activity logs track all operations.

Secure credential handling

Entra client secrets and SFTP passwords are stored in macOS Keychain. Factory reset securely wipes all profiles, secrets, logs, and app data from the device.
