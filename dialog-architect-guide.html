Dialog Architect

Admin Guide

Dialog Architect is a native macOS application that helps Mac administrators build, preview, and deploy enrollment workflows without writing code or editing XML by hand.

What It Does

Dialog Architect supports two workflow families from one app:

  • Jamf Setup Manager workflows that export as .mobileconfig profiles
  • swiftDialog workflows that export as installable .pkg packages

The goal is to let admins build, preview, validate, and ship these workflows from a native Mac interface instead of manually assembling configuration files, shell glue, and packaging steps.

System Requirements

  • macOS 14 or later
  • Apple Silicon or Intel Mac
  • About 50 MB for the app itself
  • Jamf Pro 10.35 or later for API integration workflows
  • swiftDialog 2.3 or later when using swiftDialog workflows
  • Setup Manager 1.0 or later when using JSM workflows

First Launch

On first launch, Dialog Architect opens a welcome experience with two product paths:

  • Jamf Setup Manager
  • swiftDialog

The guided setup wizard then walks through workflow choice, optional Jamf Pro connection setup, dependencies, and readiness checks before you begin your first real project.

The Interface

Dialog Architect uses a three-panel layout:

  • Sidebar for projects, templates, search, and recent files
  • Editor for the section-based visual configuration workflow
  • Preview for live output and summary information

The toolbar gives quick access to simulation, preview XML, quick testing, export, and preview visibility controls.

Jamf Setup Manager Workflows

JSM projects can include content, branding, enrollment actions, user entry fields, runtime settings, identity and variable handling, post-completion actions, help content, and localization.

  • Branding with light and dark mode variants
  • Action types such as Jamf Policy, Installomator, Shell Command, Watch Path, Wait, and Inventory Update
  • User entry fields for department, building, asset tag, computer name, and more
  • Runtime choices such as Enrollment vs Login Window, final action, and DEBUG mode

swiftDialog Workflows

swiftDialog projects focus on building dialog windows, onboarding flows, notifications, and compliance workflows.

  • Title, subtitle, message, footer, icon, banner, and accent color
  • Primary, secondary, and info buttons
  • Text fields, secure fields, and dropdown inputs
  • Progress lists linked to installers, scripts, or app steps
  • Window sizing, positioning, timer, keep-on-top, blur, and version pinning

Preview and Simulation

The built-in preview helps with layout and branding, but the real testing tools are the simulator and preview commands.

  • Live preview panel for continuous feedback while editing
  • Full-screen JSM simulator with speed controls and form testing
  • swiftDialog preview that runs the actual binary locally
  • Mobileconfig XML preview with search, copy, and upload actions

Exporting and Deploying

JSM workflows export as .mobileconfig profiles. swiftDialog workflows export as .pkg installers that can contain scripts, JSON configuration, LaunchDaemon content, and optional dependency installers.

  • Save JSM profiles to disk or upload directly to Jamf Pro
  • Generate swiftDialog packages from the build workflow
  • Quick Test for rapid JSM iteration
  • Validation badges for blocking errors and non-blocking warnings

Package Signing and Notarization

Dialog Architect includes workflows for package signing and Apple notarization, which matters when exported packages need to pass Gatekeeper and enterprise distribution checks.

  • Developer ID Installer discovery from your login Keychain
  • Signing identity selection in Preferences
  • Optional notarization using a stored notarytool keychain profile
  • Post-export signature verification

Jamf Pro Integration

Jamf Pro integration is one of the app’s strongest admin-facing features. It supports API-driven access to resources needed for both workflow authoring and deployment.

  • Server URL, Client ID, and Client Secret configuration
  • Connection testing from inside the app
  • Profile browsing, import, creation, update, and diff review
  • Department and building retrieval for dropdown-based user entry fields

Templates and Sharing

Built-in templates help admins start with proven workflow patterns, and project templates can be shared between team members.

  • Built-in workflow templates for common JSM and swiftDialog scenarios
  • .dialogtemplate export for team sharing
  • Import path that reapplies local preferences such as organization defaults

Preferences and Shortcuts

Preferences cover general defaults, signing identities, and Jamf Pro configuration. Keyboard shortcuts support fast project creation, previewing, quick testing, exporting, browsing Jamf Pro resources, and toggling preview.

Troubleshooting Themes

  • Missing dependencies such as swiftDialog or Setup Manager
  • Signing failures caused by the wrong certificate type
  • Notarization failures from invalid or missing stored credentials
  • Jamf Pro connection errors caused by URL, permissions, or expired credentials
  • Preview or simulator mismatches versus real runtime behavior

Beta Note

Dialog Architect is currently in invite-only beta. The guide is public because it helps admins understand whether the product fits their workflow before requesting access, but the installer itself is still shared privately with approved testers.
