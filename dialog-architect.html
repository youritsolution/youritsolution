SAB Dialog Architect

Build Jamf Setup Manager and swiftDialog workflows without hand-editing XML or shell glue.

SAB Dialog Architect is a native macOS app for Mac administrators who want to build, preview, validate, export, and deploy enrollment or dialog workflows from one visual editor. It supports both Jamf Setup Manager mobileconfig profiles and swiftDialog package workflows, with Jamf Pro integration included.

What It Does

One Mac app for designing, previewing, and shipping enrollment experiences.

Jamf Setup Manager workflows

Build JSM mobileconfig profiles with branding, actions, runtime options, user entry fields, help content, localization, and deployment-ready identifiers from a section-based visual editor.

swiftDialog workflows

Create swiftDialog-based onboarding, notification, and compliance flows with content, buttons, inputs, progress lists, and package export without stitching the workflow together by hand.

Preview and simulation

Use the live preview panel, full-screen JSM simulator, swiftDialog preview, and XML preview to verify both layout and generated output before pushing anything into production.

Jamf Pro aware

Connect to Jamf Pro to browse resources, import profiles, fetch departments and buildings, and upload or update configuration profiles directly from the app.

Invite-Only Beta

The beta is intentional, private, and clearly separated from public releases.

Highlights

Built for Mac admins who want clearer deployment tooling, not more hand-edited plumbing.

No-code workflow editing

Build enrollment and dialog experiences through a structured editor instead of directly editing XML, shell fragments, or package payloads by hand.

Preview before production

Live previews, simulators, and preview panels make it easier to catch visual or configuration mistakes before you export or upload anything.

Signing and notarization aware

Package signing and Apple notarization are part of the documented workflow, which matters when the end result has to survive Gatekeeper and enterprise distribution standards.

Template-friendly

Built-in templates and shareable project templates make it easier for admin teams to standardize on working patterns instead of reinventing the same deployment flows repeatedly.
