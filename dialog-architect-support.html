What SAB Dialog Architect Does

  • Build Jamf Setup Manager workflows as .mobileconfig profiles
  • Build swiftDialog workflows as installable .pkg packages
  • Preview, simulate, and validate workflows before export
  • Integrate with Jamf Pro for browsing, importing, and uploading profiles
  • Support package signing and notarization workflows

What We Can Help With

  • First-run setup and choosing a workflow type
  • Jamf Pro API connection setup and permissions
  • JSM configuration, branding, user entry fields, and runtime options
  • swiftDialog dialog design, buttons, inputs, and progress-list behavior
  • Export, upload, signing, or notarization questions
  • Simulator, preview, or validation mismatches

Before Contacting Support

Please include:

  • Your macOS version and Mac model
  • The SAB Dialog Architect version
  • Whether the issue affects Jamf Setup Manager, swiftDialog, or both
  • The export or upload step you were attempting
  • Any Jamf Pro error, signing error, notarization error, or screenshot that helps explain the problem

Privacy Reminder

If you share logs, XML, screenshots, exported packages, or diagnostics, review them first for tenant names, client IDs, branding assets, URLs, or environment details you do not want to disclose.
