SAB Dialog Architect

Invite-Only Beta Access

SAB Dialog Architect is currently shared as a private beta. The website explains the product publicly, but the installer is only distributed directly to approved testers.

Current Status

SAB Dialog Architect is not a public website download yet. Beta installers are sent privately to invited testers so feedback can be gathered without pretending the product is already generally available.

Before requesting access, you can watch the SAB Dialog Architect demo on YouTube for a quick feel of the product.

Who Should Request Access

  • Mac administrators working with Jamf Setup Manager workflows
  • Admins building swiftDialog onboarding, notification, or compliance flows
  • Jamf Pro administrators who want to test import, upload, and preview workflows
  • Beta testers willing to share structured feedback from real admin use

How Beta Access Works

  1. Request beta access by email
  2. Share a little context about your environment and what you want to test
  3. If approved, you receive the installer privately
  4. You also receive access to the private GitHub beta hub for discussion, feedback, and update notes
  5. Use that private beta hub or the support email for feedback, bugs, and workflow notes during the beta

Already Invited?

If you already received a beta invitation, use the private installer link or package shared directly with you. The public website intentionally does not host the beta installer or the beta discussion forum.

What To Include In Your Request

  • Your role and environment, such as MSP, internal IT, or consultant
  • Whether you mainly care about Jamf Setup Manager, swiftDialog, or both
  • Your Jamf Pro usage level, if applicable
  • Your macOS version and whether you use Intel or Apple Silicon Macs
  • Whether you are comfortable sharing structured beta feedback

Request Beta Access

Email: support@youritsolution.dk

If approved, you will be invited to the private GitHub beta hub and given the private installer path directly.

You can also start by reading the Admin Guide if you want to understand the workflow depth first.
