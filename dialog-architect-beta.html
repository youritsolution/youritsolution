SAB Dialog Architect

Download and Get Started

SAB Dialog Architect is a free, signed, and notarized macOS app. Download the installer, open it, and start building Jamf Setup Manager or swiftDialog workflows right away.

Download

Download SABDialogArchitect-latest.pkg

SHA-256 checksum

  • Signed with Developer ID and notarized by Apple
  • Universal binary — Intel and Apple Silicon
  • Requires macOS 14 (Sonoma) or later

Getting Started

  1. Download and open the .pkg installer
  2. Launch SAB Dialog Architect from your Applications folder
  3. Choose a workflow type: Jamf Setup Manager or swiftDialog
  4. Create a new project or start from a built-in template
  5. Use the visual editor to build your workflow
  6. Preview and simulate to verify before exporting
