Hobby-Driven Software

I build free tools for real frustrations.

Your IT Solution is a personal project built in my free time. I create tools that solve real-life frustrations I have run into myself, then share them so other people do not have to fight the same problems from scratch.

Some of these apps are focused Mac utilities, others are deeper admin workbenches, but the goal is the same every time: practical software that earns its place by being genuinely useful.

SAB Enroll Hub

A Mac-native control center for Apple device enrollment across multiple organizations.

SAB Enroll Hub is built for administrators who manage devices across Apple Business Manager and Apple School Manager. It brings device inventory, DMS assignment, cross-portal search, bulk actions, export, and diagnostics into one desktop workflow.

  • Multi-org ABM and ASM management from one Mac app
  • Cross-portal search for serials, models, orders, orgs, and DMS clues
  • Bulk assignment and export workflows designed for real admin use
  • Keychain-backed private key storage and local diagnostics

SAB Workspace

A Mac-native workspace for Intune backup, migration, reporting, and tenant review.

SAB Workspace is a native macOS admin tool for Microsoft Intune and Entra. It helps teams export tenant configuration into reusable packages, compare live tenants or packages, dry-run imports safely, copy supported workloads across tenants, and generate reports, architecture summaries, and diagnostics.

  • Guided export, compare, import, copy, and transform workflows
  • Architecture reports, executive summaries, and diagnostics bundles
  • Support for specialist tools such as Administrative Templates and Registry Values
  • Built for Mac-based consultants, MSPs, and enterprise administrators

SAB Assign

A Mac-native control desk for bulk Intune assignment and unassignment work.

SAB Assign is a native macOS admin tool for Microsoft Intune teams who need to apply or remove assignment logic across many resources without repeating the same portal steps one object at a time.

  • Bulk workflows for apps, settings catalog, configuration profiles, and compliance policies
  • Current assignment inspection before applying changes
  • Evidence export for change control and audit support
  • Mock mode and guided Microsoft Graph setup

SAB VM Lab

Create and manage virtual Macs with a polished native workflow.

SAB VM Lab is a native macOS app for creating virtual macOS machines on Apple silicon. It focuses on a smooth setup experience, flexible VM storage, restore image management, shared folders, hardware tuning, save and restore state, and clear day-to-day VM administration.

  • Native SwiftUI and AppKit experience designed for macOS
  • Self-contained VM bundles for backup, restore, and portability
  • Apple silicon guest support powered by public Virtualization APIs
  • Direct-download friendly architecture with room for advanced utilities

SAB Dialog Architect

A native macOS builder for Jamf Setup Manager and swiftDialog workflows.

SAB Dialog Architect is built for Mac administrators who want to design, preview, export, and deploy enrollment or dialog workflows without writing XML by hand or stitching shell scripts together from scratch. It supports Jamf Setup Manager mobileconfig profiles and swiftDialog package workflows from one visual editor.

  • Visual editor for Jamf Setup Manager and swiftDialog workflows
  • Live preview, full-screen simulation, and XML inspection tools
  • Jamf Pro integration for browsing, uploading, and importing profiles
  • Signed and notarized direct-download installer
