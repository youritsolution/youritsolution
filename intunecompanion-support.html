Intune Companion

Support

Intune Companion is a native macOS administration workspace for Microsoft Intune and Microsoft Entra.

Contact

Support email: support@youritsolution.dk

Public GitHub feedback hub: Intune-Companion

Feedback and Discussion

Intune Companion uses GitHub as the public feedback and release hub.

  • Discussions is the main place for help, questions, ideas, and general feedback
  • Issues is for bugs and feature requests
  • Releases is the public app hub

If you prefer not to use GitHub, you can still contact support directly by email: support@youritsolution.dk

What Intune Companion Does

  • Connect to Microsoft Intune and Entra tenants
  • Export tenant configuration into reusable packages
  • Compare packages or compare a package against a live tenant
  • Dry-run and run supported import workflows
  • Copy supported workloads between tenants
  • Generate reports, executive summaries, and diagnostics bundles

What We Can Help With

  • Connection setup and Microsoft sign-in issues
  • Export package generation problems
  • Compare and drift review questions
  • Import dry-run, mapping, or validation blockers
  • Diagnostics bundle questions
  • App release and availability questions

Before Contacting Support

Please include:

  • Your macOS version and Mac model
  • The Intune Companion version
  • The workflow you were using, such as Export, Compare, Import, Copy, or Transform
  • A short description of the issue
  • Any Microsoft Graph error message or request ID shown in the app
  • A diagnostics bundle if you are comfortable sharing it after reviewing it first

Availability

Intune Companion is being prepared for public distribution. The website support path and public GitHub hub are in place now so users have a stable place for help and feedback.

Public releases will appear at GitHub Releases when distribution is live.

Privacy Reminder

If you choose to send logs, reports, or diagnostics bundles, review them first for tenant names, object names, email addresses, file paths, or other details you do not want to share.

For privacy details, see the Intune Companion Privacy Policy.
