Before Contacting Support

Please include:

  • Your macOS version and Mac model
  • The SAB Enroll Hub version
  • The organization type involved, Business or School
  • A short description of the issue and the workflow you were using
  • Any Apple API error code shown in the app
  • An exported diagnostics archive if you are comfortable sharing it after review

Logs and Diagnostics

Use Help > Open Logs Folder to access log files. The diagnostics panel also offers an encrypted diagnostics export containing sync metrics and audit data that can help support troubleshoot issues faster.

Privacy Reminder

If you choose to send screenshots, logs, or diagnostics archives, review them first for organization names, serial numbers, server names, email addresses, and other details you do not want to share.

For privacy details, see the SAB Enroll Hub Privacy Policy.
