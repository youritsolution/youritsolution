SAB Audio

Support

Help getting started, solving common issues, and reaching the developer when you need to.

Getting Started (iOS)

On first launch, SAB Audio will ask you to import audio. Choose Import Folder and select any folder in your iCloud Drive that contains audio files. The app reads the metadata in the background and your library appears within seconds.

Files are not copied. SAB Audio references them in place using Apple's security-scoped bookmark system, so 4,000 tracks take zero device storage you didn't already have in iCloud.

Getting Started (Android)

On first launch, SAB Audio will ask you to import audio. Choose Import Folder and pick any folder on your device (or in a connected cloud provider exposed through the system file picker — Google Drive, OneDrive, Dropbox, etc.) using the Android Storage Access Framework dialog. You can also pick individual files with Import Files.

Files are not copied. SAB Audio holds a persisted read permission on the folder you granted and references each file in place. You can revoke that permission at any time from Android system settings.

Import Tips

  • Supported formats include MP3, M4A (AAC + ALAC), FLAC, WAV, AIFF, AAC, M4B audiobooks, OGG/Opus, and CAF
  • For best library hygiene, organize your source as Artist / Album / Track — the Folder browser mirrors that hierarchy on both platforms
  • Embedded artwork is read at import; the app caches a 300×300 JPEG for fast scrolling
  • If a track imports without metadata, enable MusicBrainz enrichment in Settings to fill it in
  • On Android, large imports run in a background coroutine so a screen-off or app-switch does not interrupt them

Common Questions

"My track has no artist or album." — The file likely lacks embedded metadata. Open Settings → Maintenance → Listening History to see if MusicBrainz can fill it, or use the Tag Editor to enter values manually. Manual edits are preserved across re-scans.

"A track says 'Needs Repair' or won't play." — The original file may have moved or been renamed (in iCloud Drive on iOS, or in the folder you granted access to on Android). Use Settings → Repair Broken Links to reconnect references without losing play count or playlist membership.

"I'd like to listen offline on a flight." — On iOS, long-press a track or use multi-select → Pin for Offline; iCloud Drive will download the file and Settings → Offline Downloads shows progress. On Android, files imported from on-device folders are already local — they always play offline without any extra step.

"Is there a CarPlay / Android Auto version?" — Not in v1.0 on either platform. CarPlay (iOS) and Android Auto are part of the v1.1 Pro update, which will be a one-time in-app purchase on top of the free app. Until then, listen via AirPlay (iOS) or a Bluetooth car stereo.

Audiophile Tips

  • Enable Pure Mode in Settings for bit-perfect output — every DSP stage bypassed
  • Connect a USB DAC (Lightning or USB-C on iOS; USB-C on Android) and SAB Audio will request the source's native sample rate
  • Run Settings → Audio Quality → Analyze Library once to measure loudness across your entire library
  • Set per-output EQ memory on, then save a different preset for each pair of headphones — the app applies them automatically as the route changes
  • On Android, 24-bit and 32-bit PCM files play through the DSP chain at native bit depth — no down-conversion to 16-bit

Privacy

SAB Audio collects nothing. No analytics, no ads, no tracking. The two optional network integrations (MusicBrainz metadata and Last.fm scrobbling) are off by default. Read the full privacy policy.
