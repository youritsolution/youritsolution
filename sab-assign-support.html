Current Release Status

SAB Assign is being prepared for Apple App Store distribution.

This support page is live now so administrators have a stable place for help and product information before the public release is available.

What SAB Assign Does

  • Browse Intune apps, settings catalog policies, configuration profiles, and compliance policies
  • Inspect current assignments before making changes
  • Build one assignment plan and apply it across many selected resources
  • Unassign only matching assignments instead of wiping everything
  • Export evidence for change control and audit purposes
  • Use mock mode for safe learning and workflow testing

What We Can Help With

  • First-run setup and Magic Setup questions
  • Microsoft Graph connection failures
  • Assignment or unassign plan validation questions
  • Filter, group, or app intent confusion
  • Evidence export and audit workflow questions
  • Troubleshooting load failures, throttling, or partial failures

Before Contacting Support

Please include:

  • Your macOS version and Mac model
  • The SAB Assign version
  • Whether you were in mock mode or live mode
  • The section you were working in, such as Apps or Compliance
  • The operation you attempted, such as Apply, Unassign, or Export Evidence
  • The exact Microsoft Graph error, request ID, or screenshot if available

Privacy Reminder

If you choose to share logs, evidence exports, screenshots, or error output, review them first for tenant names, group names, policy names, or identifiers you do not want to share.

For privacy details, see the SAB Assign Privacy Policy.
