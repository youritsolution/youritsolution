EnrollPilot

A Mac-native admin tool for multi-organization Apple device enrollment operations.

EnrollPilot is designed for ABM and ASM administrators who need a clearer way to work across multiple organizations. It focuses on device inventory, DMS server assignment, cross-portal search, bulk actions, export, diagnostics, and secure credential handling.

  • Works across Apple Business Manager and Apple School Manager organizations
  • Cross-portal search, DMS assignment, bulk device actions, and CSV export
  • Keychain-backed private key storage with local diagnostics and audit support
  • Signed direct-download installer plus public GitHub discussions and issues

Intune Companion

A Mac-native workspace for Intune migration, tenant review, and documentation.

Intune Companion is a native macOS admin workspace for Microsoft Intune and Entra. It helps administrators export tenant configuration, compare packages and live tenants, transform reusable packages, dry-run imports, copy supported workloads, and generate reports and diagnostics from one focused desktop tool.

  • Export, compare, import, copy, and transform workflows
  • Architecture reports, executive summaries, and diagnostics bundles
  • Administrative Templates, Registry Values, and specialist Intune tooling
  • Public GitHub hub for releases, discussions, and issue tracking

Intune Bulk Assigner

A Mac-native assignment workbench for Microsoft Intune bulk targeting changes.

Intune Bulk Assigner is designed for administrators who need to review current assignments, build one assignment plan, and then apply or remove matching assignments across many Intune resources in a safer, more controlled way.

  • Bulk assignment and unassignment across apps, settings catalog, configuration profiles, and compliance policies
  • Current-assignment inspection before change execution
  • Evidence export for CAB, audit, and rollback planning
  • Mock mode and guided Microsoft Graph app-registration setup

SAB VM Lab

Create and manage virtual Macs with a polished native workflow.

SAB VM Lab is a native macOS app for creating and managing virtual macOS machines on Apple silicon. It includes flexible VM storage, direct-download support, shared folders, guest tools, hardware tuning, cloning, and day-to-day VM management in a more approachable Mac-native experience.

  • Direct download with signed and notarized installer package
  • Finder-friendly shared folders and guest tools
  • Expandable virtual disk growth after installation
  • GitHub releases, issues, and discussions for the public app hub
