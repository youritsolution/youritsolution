Feedback and Discussion

SAB VM Lab has its own public GitHub hub for releases and feedback. That gives users a clear place to give feedback, ask questions, share ideas, and discuss the app outside of email.

  • Discussions is the main feedback page for questions, help, ideas, and general feedback
  • Issues is for bugs and feature requests
  • Releases is the public app hub

If you prefer not to use GitHub, you can still send feedback directly by email: support@youritsolution.dk

  • App Store build and sandbox behavior questions

Before Contacting Support

Please include:

  • Your Mac model and host macOS version
  • The SAB VM Lab version
  • A short description of the issue
  • Whether the issue happens during install, startup, or while the VM is running
  • Any error message shown in the app

Privacy Reminder

If you choose to send logs or screenshots, please review them first for local file paths, machine names, or other details you do not want to share.

For privacy details, see the SAB VM Lab Privacy Policy.
