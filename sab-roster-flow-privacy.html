SAB Roster Flow

Privacy

How SAB Roster Flow handles your data, credentials, and what leaves the device.

Data Processing

  • SAB Roster Flow reads user and group data from Microsoft Entra ID via Microsoft Graph API
  • Data is processed locally on your Mac to generate Apple School Manager compatible CSV files
  • Generated CSV files are uploaded to Apple School Manager via SFTP when you initiate a sync
  • No data is sent to Your IT Solution or any third party

Credential Storage

  • Entra ID client secrets are stored in macOS Keychain, not in the app database
  • SFTP passwords are stored in macOS Keychain, not in the app database
  • Credentials are retrieved at runtime only when needed for API calls or SFTP connections
  • Factory reset removes all Keychain entries created by the app

Local Storage

  • Sync profiles, field mappings, role rules, and class selections are stored locally using SwiftData
  • Activity logs and run reports are stored in the app Documents directory
  • Manual CSV exports are saved to a folder you choose
  • Temporary files used during upload are deleted automatically after each sync

Network Connections

  • Microsoft login.microsoftonline.com: OAuth token acquisition
  • Microsoft graph.microsoft.com: User, group, and membership data retrieval
  • Apple School Manager SFTP endpoint: CSV package upload
  • No other network connections are made by the app

Decommission

  • Factory Reset (File menu) removes all profiles, mappings, secrets, logs, caches, and preferences
  • Requires explicit confirmation by typing DELETE before execution
  • Deletes Keychain entries, Application Support data, Documents content, and user defaults

Analytics and Telemetry

SAB Roster Flow does not collect analytics, telemetry, crash reports, or usage data. All processing is local.
